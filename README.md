# Huzaifa Ramzan — Portfolio Website

A responsive single-page portfolio for a Shopify Developer and Digital Marketing Specialist. Built with plain HTML, CSS and JavaScript for easy GitHub Pages hosting.

## Included
- `index.html` — page content and structure
- `style.css` — white/green visual design and responsive layout
- `script.js` — mobile navigation, active nav state, email-form helper
- `assets/profile.jpg` — supplied portrait
- `assets/Huzaifa_Ramzan_CV.pdf` — downloadable CV
- `assets/favicon.svg` — HR favicon

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `portfolio`.
2. Extract this project ZIP on your computer.
3. Open the extracted `huzaifa-portfolio` folder and upload the *contents* into the repository root (so `index.html` is visible at the top level, not inside another folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait for GitHub Pages to publish. The address usually becomes `https://YOUR-USERNAME.github.io/portfolio/`.

## Personalize before publishing
- Confirm the GitHub username/link you want to display if you later add social links.
- The `fashiontex.store` URL and contact details are currently set from the supplied details.
- The contact form opens the visitor's email app using `mailto:`. A static GitHub Pages site does not process/store form submissions by itself.
- Skill bars are illustrative design indicators, not objective proficiency ratings; edit or remove them in `index.html` if you prefer.

## Local preview
Double-click `index.html` to preview the site in a browser. Some browsers may restrict parts of local navigation; GitHub Pages is the intended deployment target.
